=== DOTA 2 BUY HELPER v3.7 ===
Ассистент по закупу в стиле чита

============================================
ЧТО УМЕЕТ:
============================================

🟢 СТАРТОВЫЙ ЗАКУП
- Вводишь врагов — получаешь закуп на 600 золота
- Учитывает твоего героя (керри/танк/саппорт)

💀 ПОСЛЕ СМЕРТИ
- Вводишь цифры из панели смерти
- Бот подбирает что купить под твоё золото

📌 ПОВЕРХ ВСЕХ ОКОН
- Жми кнопку в программе
- Бот висит поверх Доты

⌨️ ПРАВЫЙ ALT
- Быстрый вызов без сворачивания игры

🕹️ МИНИ-ИГРА
- Жми красную кнопку [ВЗЛОМ VAC]
- Долби ПРОБЕЛ для взлома!

============================================
КАК ПОЛЬЗОВАТЬСЯ:
============================================

1. Запусти dota_bot.exe
2. Введи своего героя:
   - КЕРРИ: pa, juggernaut, sniper, drow, am, void
   - ТАНК: axe, bristleback, pudge, tidehunter
   - САППОРТ: lion, dazzle, oracle, warlock

3. Введи врагов через пробел:
   Например: zeus pa lion huskar

4. Жми [ СТАРТОВЫЙ ЗАКУП ]

5. После смерти:
   - Открой панель смерти в Доте
   - Введи: урон с руки, урон способностей, контроль (сек)
   - Введи своё золото
   - Жми [ ПОКАЗАТЬ ЧТО КУПИТЬ ]

============================================
ВАЖНО:
============================================

- Пиши героев на английском (pa, zeus, lion...)
- Золото сохраняется автоматически
- Это НЕ чит — программа не лезет в игру
- VAC безопасен — это просто калькулятор закупа
